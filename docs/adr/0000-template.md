# NNNN. Title in plain words, stating the decision

- Status: Proposed | Accepted | Superseded by [NNNN](NNNN-title.md)
- Date: YYYY-MM-DD
- Story: S0-x (or "none")
- Deciders: who made the call (for example tegs, PM, BackendDev)

## Context

What problem forced a choice, and the facts that shaped it. Write for someone joining in a year
who asks "why did we do it this way?".

## Options considered

- **Option A.** One line on what it is, its main upside and downside.
- **Option B.** Same.

## Decision

What we chose, stated so it can be checked against the code.

## Consequences

What gets easier, what gets harder, and what we must now do (tests, follow-ups, limits). Name the
trigger that should make us revisit this.
